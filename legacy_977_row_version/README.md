# Legacy: first version (977 payloads)

Kept for history. **Do not cite the results in this folder.**

This was the first version of the project: 977 hand-assembled payloads (477 SSTI, 500 benign) evaluated on a single random 80/20 split. That split ignored payload variants, so near-identical payloads could appear in both training and test data, which inflates the scores. The benign examples were also authored rather than collected.

It is replaced by the dataset, features and evaluation in the parent folder.
